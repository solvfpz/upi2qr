Generate dynamic payments in milliseconds.

## Features
- **Universal Support**: Works with UPI (GPay, PhonePe, Paytm, BHIM) and Crypto (LTC, USDT).
- **Auto-Detection**: Zero manual effort—detects crypto addresses automatically.
- **Privacy Focused**: No data stored. All QR generation happens locally.
- **High Quality**: Instant, downloadable PNG codes.

## Getting Started
1. `npm install`
2. `npm run dev`
